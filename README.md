# Insider Mortgage

Welcome to the **Insider Mortgage** platform repository!

This project is a modern, blazing-fast web application built for the Insider Mortgage team. It is designed to provide clients with top-tier tools, beautiful aesthetics, and seamless user experiences.

## Features
- **Dynamic Mortgage Calculators:** Includes DSCR Cash Flow analysis and a unique "Utility" calculator for solving missing loan variables.
- **Specialized Loan Pages:** Dedicated, SEO-optimized landing pages for Bank Statement Loans, 1099 Contractors, and Retirees.
- **Live Economic Data:** Features baked-in, interactive yield curve and treasury spread charts utilizing data from the Federal Reserve (FRED).

## Technology Stack
- **Framework:** React + Vite
- **Styling:** Custom CSS with modern glassmorphism UI patterns
- **Charting:** Recharts
